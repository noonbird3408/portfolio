## 프로젝트

### 쑥쑥 (SSUKSSUK) · 4인 팀 프로젝트

학생 관리, 출결, 수납, 재고 관리 등 교육 시설의 운영 업무를 한곳에서 처리하는 웹 서비스입니다. 운영자는 시설 현황을 확인하고, 학부모는 연결된 자녀의 출결과 청구 내역을 조회할 수 있습니다.

- **문제**　학생 정보, 출결, 수납을 따로 확인해야 하는 운영 흐름을 한 서비스로 모으고자 했습니다.
- **기여**　React 프론트엔드와 FastAPI 백엔드 개발에 참여했습니다. 팀원이 작업한 코드를 합치는 과정에서 발생한 통합 오류를 해결하고, Supabase와 Vercel을 사용한 배포에 참여했습니다.
- **결과**　운영자가 학생 관리와 출결·수납 업무를 처리하고, 학부모가 관련 정보를 확인할 수 있는 웹 서비스를 배포했습니다.
[쑥쑥 GitHub 저장소](https://github.com/noonbird3408/b2b)

### 모음달력 (Moeum Calendar) · 개인 프로젝트

여러 모임의 일정을 한 달력에서 보고, 구성원 모두가 가능한 시간을 찾을 수 있는 공유 캘린더입니다.

- **문제**　모임마다 일정이 흩어져 있으면 내 일정을 한눈에 보기 어렵고, 약속을 잡을 때 구성원들의 빈 시간을 일일이 맞춰야 합니다.
- **내 기여**　가입한 캘린더의 일정을 한 화면에 모으고, 개인·단체 일정에서 바쁜 시간대를 합쳐 모두가 비어 있는 날짜와 시간대를 계산하는 기능을 구현했습니다.
- **결과**　구성원이 초대 링크로 참여해 일정을 공유하고 가능한 시간을 확인할 수 있도록 서비스를 배포했습니다. 기획과 개발에는 React, TypeScript, Supabase를 사용했고 Vercel에 배포했습니다.
[모음달력 GitHub 저장소](https://github.com/noonbird3408/moeum_calendar)
